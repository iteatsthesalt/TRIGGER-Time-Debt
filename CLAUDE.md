# TRIGGER: Time Debt

You are building the complete game described in `design/`:

- `STORY_BIBLE.md` for story.
- `COMBAT_LAWS_BIBLE.md` for combat.
- `REFERENCE_BIBLE.md` for art, audio, and the creation briefs and asset manifest.

You have full creative authority. Generate every asset the game needs, fill any gap the bibles leave, and retune anything that makes the game better.

Each session starts on a blank computer:

1. Run `git pull`, then read `PROGRESS.md`.
2. Run `source tools/setup_godot.sh` to get Godot 4.7.2.
3. Commit and push after each working step. Only pushed work survives.
4. Before ending, update `PROGRESS.md` (what exists, what's next, known issues), then commit and push.

See `README.md` for the repository map and commands. `prototype/` holds a working combat core to reuse.
