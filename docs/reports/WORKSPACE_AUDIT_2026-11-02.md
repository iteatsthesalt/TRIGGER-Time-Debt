# Workspace audit, 2026-11-02

**Scope.** Everything in the workspace: the game repository (`iteatsthesalt/TRIGGER-Time-Debt`, branch
`ccr-71b3659f-ryo8fv`, draft PR #1), the retired combat prototype (`iteatsthesalt/Trigger`, draft PR #6), the three
documents Nich uploaded that day (the Nov 1 *Chrono-Style Recreation Breakdown*, the *Chrono Apocrypha Master Design
Bible*, the *Hybrid Chrono/Octopath Combat Architecture*; the first and last are now under `design/`), the asset
team's Slack, Linear, Dropbox and Notion trail, and the PixelLab account.

**Method.** Two multi-agent audits, each adversarially verified, then a fix pass and a final integration review.
The docs and direction audit ran seven finders over seven topics (the breakdown, the uploaded bible, the
architecture note, the hand-off documents, the prototype snapshot, repository hygiene, the asset pipeline) with a
refuter per finding: 149 findings, 140 confirmed, 9 refuted. The code audit ran seven readers, seven finders and
fourteen refuters over BATTLE, COMBAT, CORE, WORLD, STORY, DATA and TOOLS, then a completeness critic that opened
four gap sweeps (post-battle restore, save and resume, acceptance and probe fidelity, uncovered files and
toolchains), each refuted again: 204 findings, 183 confirmed, 16 plausible, 5 refuted. Every confirmed or plausible
code finding went into one of fifteen fix clusters (section C).

**Where things stand.** Every verified finding is fixed or carries a recorded reason. The gate is green on the
branch head: 3,494 unit checks in 17 suites, the data lint, 30 Python tool tests, three headless probes (the
Prologue, Chapter 1, the Atrium Cradle), a smoke boot and two scene captures that were looked at. What remains is in
`PROGRESS.md`: mostly content (Leene Square, the Chapter 2 scenes, boss directors that come with their chapters),
the style gate Nich owns, and a short list of engine items.

**Open for Nich.** Every decision only he can make is in `docs/QUESTIONS_FOR_NICH.md`; section D summarises what
this audit added.

## B. Docs, direction, prototype, hygiene and asset-pipeline audit (7 finders, 7 refuters)

### B.1 The Nov 1 style breakdown against the project

The breakdown and the project agree on the skeleton and disagree on the skin. Already true, and verifiably so: battles are a state inside the field scene (location.gd:456-458), Forward+ with nearest UI filtering, no FXAA/SMAA, 640×360 integer canvas, ambient light above zero, alpha-scissor billboards that cast shadows, lossless no-mipmap sprite imports, per-frame hold timing, a PixelLab workflow that already uses low top-down, 8 directions, a Crono style anchor, the same template clip ids and a never-resize rule, and a leitmotif-driven score.
